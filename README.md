# AI Technical Interview Room - Candidate Side

An advanced AI-powered technical interview platform designed to provide a seamless and interactive experience for candidates.

## 🚀 Key Features

- **Live AI Interviewer**: Real-time voice and video interaction using Google's Gemini Multimodal Live API.
- **Real-time Transcription**: Instant speech-to-text for both the candidate and the AI.
- **Premium UI/UX**: A modern, responsive interface with smooth animations and interactive components.
- **Backend Integration**: Structured storage for interview transcripts and candidate data.

## 🛠 Tech Stack

- **Frontend**: Next.js, TypeScript, Tailwind CSS, Framer Motion
- **AI**: Gemini Multimodal Live API
- **Backend**: Node.js, Express
- **State Management**: React Hooks
